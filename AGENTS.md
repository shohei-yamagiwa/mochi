# AGENTS.md

Rules for AI agents working in this repository.

## Language

- Write all documentation and all content on GitHub (pull requests, issues, comments, and similar) in English.

## Comments in code

- Add comments only to code that is invariant and non-obvious.
- Never leave comments that are valid only at a specific point in time, such as references to the change being made, a temporary state, or a past discussion. Such comments are especially obstructive and must not remain in the codebase.

## Proposals and decisions

- Treat every opinion or proposal you make as undecided unless the user has explicitly approved it.
- Never record, implement, or refer to your own proposal as a decided matter on your own authority.
